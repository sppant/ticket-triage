# How feature requests work

We read every feature request, and the most requested ideas shape the roadmap. Ideas such as keyboard shortcuts, custom label colors, bulk editing, a mobile widget or PDF export are tracked on our public feedback board, where you can vote and follow progress.

Requests are not scheduled individually; we reply when something ships. Do add your use case, because it helps us prioritize. Bulk edit and keyboard shortcuts are currently under consideration.

Customers with a deadline or a compliance need should say so in the request, so we can route it to the right team.
